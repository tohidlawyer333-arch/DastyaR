# DastyaR — دستیار دفتر وکالت

برنامهٔ دسکتاپ ویندوزی فارسی و راست‌چین برای مدیریت دفتر وکالت. تنها برنامه‌ای که کاربر باز می‌کند DastyaR است؛ Goose CLI در پشت صحنه به‌صورت فرایند داخلی و از طریق ACP اجرا می‌شود و پنجرهٔ مستقل Goose Desktop باز نمی‌شود.

## وضعیت آغازین

این مخزن تازه راه‌اندازی شده است. نسخهٔ آغازین شامل پوستهٔ Electron، پل ACP برای Goose، خزانهٔ محلی رمزگذاری‌شده، مدیریت اولیهٔ موکلان و پرونده‌ها، قالب‌های متغیر، ثبت منابع حقوقی، واردکردن فایل و آرشیو ZIP/RAR/7z، مرورگر داخلی عدل ایران و گردش ساخت ویندوز است.

**این نسخه هنوز برای کار روی اسناد واقعی موکلان آمادهٔ بهره‌برداری نهایی نیست.** استخراج خودکار پرونده‌ها و ابلاغیه‌های ثنا، تحلیل محتوای فایل‌های رمزگذاری‌شده توسط عامل، OCR، تشخیص گفتار فارسی و ترکی آذربایجانی، ترجمهٔ هم‌زمان، اتصال کامل ابزارهای کنترل ویندوز، و دروازهٔ تأیید مستقل برای تمام اقدامات بیرونی باید در فازهای بعدی پیاده‌سازی و آزمون شوند. ارسال نهایی هر سند قضایی باید همواره تأیید صریح وکیل بخواهد.

## معماری

- رابط مستقل DastyaR: فارسی و RTL؛ تنظیمات، ابزارها و تأییدها داخل همین برنامه هستند
- موتور عامل: Goose CLI به‌صورت پس‌زمینه از طریق ACP؛ نسخهٔ رسمی ویندوز در CI دریافت و SHA-256 آن بررسی می‌شود
- پنجره‌های وب/ورود به ارائه‌دهندگان متعلق به DastyaR هستند؛ اجرای Goose Desktop جداگانه لازم نیست
- پیکربندی اولیهٔ MCP از داخل تنظیمات ممکن است؛ هر افزونهٔ خارجی باید جداگانه بررسی شود
- خزانه: AES-256-GCM با کلید مشتق‌شده از گذرواژه و scrypt
- فایل‌های ضمیمه: رمزگذاری جداگانه و ذخیره با شناسهٔ تصادفی
- کلیدهای ارائه‌دهندگان: Electron safeStorage و رمزگذاری سیستم‌عامل
- خروجی: نصاب ویندوز EXE و بستهٔ ZIP قابل‌حمل از GitHub Actions

## ساخت

نیازمندی‌های ساخت محلی: Windows 10/11، Node.js 24، npm و Git. برای اجرای محلی باید فایل Goose در resources/goose/goose.exe موجود باشد یا متغیر محیطی DASTYAR_GOOSE_BIN آن را معرفی کند.

1. npm install
2. فایل Goose CLI ویندوز را از انتشار رسمی Goose دریافت کنید و پس از بررسی SHA-256 در resources/goose بگذارید.
3. npm start
4. npm run dist

گردش GitHub Actions فایل Goose نسخهٔ مشخص‌شدهٔ 1.55.0 را از انتشار رسمی می‌گیرد و digest اعلام‌شده در metadata رسمی GitHub را بررسی می‌کند؛ اگر digest معتبر در دسترس نباشد، بیلد متوقف می‌شود. سپس مجوز بالادستی را اضافه می‌کند و بستهٔ EXE و ZIP می‌سازد. برای بارگذاری سورس با GitHub Desktop، راهنمای docs/GITHUB-DESKTOP.fa.md را دنبال کنید.

## مدل‌ها و کلیدها

DastyaR کلیدی را که کاربر وارد کرده در ذخیره‌سازی امن سیستم‌عامل نگه می‌دارد و امکان رفتن به صفحهٔ رسمی کلید هر ارائه‌دهنده را فراهم می‌کند. برنامه در این نسخه کلید را با خزش صفحات، دورزدن کپچا یا عبور از کنترل‌های حساب ایجاد نمی‌کند؛ هر ورود یا ساخت کلید باید با حساب و اجازهٔ وکیل انجام شود. میزان استفادهٔ رایگان به سیاست و سهمیهٔ ارائه‌دهنده بستگی دارد و تضمین دائمی ندارد. ChatGPT/Codex با اشتراک/ورود رسمی یکسان با کلید API رایگان نیست.

## امنیت

- رمزگذاری خزانه و فایل‌های پیوست محلی است؛ گذرواژهٔ خزانه روی دیسک ذخیره نمی‌شود.
- مرورگر داخلی عدل ایران پارتیشن کوکی جدا دارد. این نسخه ابلاغیه‌ها را مخفیانه باز نمی‌کند و وضعیت مشاهده‌شدن آن‌ها را تغییر نمی‌دهد.
- متن فایل و وب‌سایت به عنوان دادهٔ غیرقابل اعتماد در نظر گرفته می‌شود.
- انتخاب حالت تأیید دستی Goose مفید است اما به‌تنهایی تضمین امنیت همهٔ افزونه‌های خارجی نیست. پیش از استفادهٔ واقعی باید تک‌تک ابزارهای MCP و مسیرهای حساس آزمون شوند.

ماتریس وضعیت واقعی و کارهای باقی‌مانده در docs/STATUS.fa.md و جزئیات معماری تک‌برنامه‌ای در docs/GOOSE-INTEGRATION.fa.md، docs/ARCHITECTURE.fa.md، docs/SECURITY.fa.md و docs/ROADMAP.fa.md آمده است. Goose تحت Apache-2.0 منتشر می‌شود؛ فایل مجوز همان نسخه در بستهٔ ویندوز قرار می‌گیرد. DastyaR پروژه‌ای مستقل است و وابستگی یا تأیید رسمی Goose یا قوه قضاییه را ادعا نمی‌کند.
