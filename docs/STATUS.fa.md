# وضعیت واقعی نسخهٔ آغازین DastyaR

این فایل بین «کد پایه موجود است» و «قابلیت نهایی و آزموده‌شده» تفاوت می‌گذارد.

| بخش | وضعیت فعلی | کار باقی‌مانده |
|---|---|---|
| برنامهٔ واحد ویندوزی | پوستهٔ Electron با نام DastyaR و اجرای Goose CLI در پشت صحنه طراحی شده | ساخت/اجرای واقعی روی Windows و آزمون همهٔ مسیرهای ACP |
| خزانهٔ محلی | رمزگذاری متادیتا و ضمیمه‌ها با AES-256-GCM در کد پیاده شده | آزمون بازیابی، پشتیبان آفلاین، مدیریت خطا و بررسی امنیتی مستقل |
| موکل و پرونده | ثبت پایهٔ موکل، پرونده و شناسه‌های پرونده | ورود دسته‌ای با تطبیق دقیق، گزارش تغییرات و مهاجرت پایگاه داده |
| بارگذاری فایل و آرشیو | فایل تکی/پوشه و استخراج موقت ZIP/RAR/7z در کد شروع شده | آزمون امنیت آرشیو، محدودیت ضد zip-bomb، پالایش نوع فایل و پوشش اسناد حجیم |
| تولید از قالب | قالب متنی با نشانگرهای `{{متغیر}}` و پیش‌نویس قابل ذخیره | واردکردن Word/PDF به‌عنوان قالب، استخراج متغیر هوشمند، حفظ دقیق صفحه‌آرایی DOCX و اعتبارسنجی خروجی |
| مدل‌های آنلاین | فهرست Gemini/OpenRouter/OpenAI/DeepSeek/Hugging Face و ذخیره‌سازی امن کلید در UI | آزمون مدل/شناسه‌های هر سرویس، OAuth واقعی Codex و بهبود راهنمای سهمیه/هزینه |
| افزونه‌های MCP | پیکربندی آغازین stdio/http/sse در خزانه و ارسال به ACP | آزمون عملی transportها، نمایش ابزارهای هر افزونه و تنظیم مجوز جزئی برای هر ابزار |
| Recipes و Subagents | امکانات وابسته به موتور Goose هستند | پنل DastyaR برای فهرست، واردکردن، ویرایش و اجرای Recipe و کنترل subagentها |
| کنترل کامپیوتر Windows | در این نسخه ادعای آماده‌بودن ندارد | ساخت/اتصال ابزارهای Windows UI Automation، اسکرین‌شات، کلیک، تایپ و آزمون امن |
| مرورگر قضایی | پنجرهٔ داخلی DastyaR با پارتیشن کوکی جدا | بررسی دقیق دامنه‌ها/تغییر مسیرها و آزمون حساب آزمایشی؛ استخراج پرونده/ابلاغیه هنوز پیاده نشده |
| منابع قانونی | ثبت عنوان، دسته‌بندی، لینک و یادداشت؛ واردکردن فایل | واکشی/استخراج متون، OCR، تقسیم‌بندی و استناد قابل‌راستی‌آزمایی |
| ضبط جلسه | ضبط محلی و نگهداری رمزگذاری‌شدهٔ فایل | STT فارسی و ترکی آذربایجانی ارومیه‌ای، زمان‌نما، تفکیک گوینده و بازبینی رونوشت |
| ارسال قضایی | عمداً در نسخهٔ آغازین فعال نیست | گیت مستقل تأیید وکیل، ثبت رخداد، آزمون سامانه و کنترل دوبارهٔ اقدام پیش از ارسال |

**هشدار:** تا قبل از تکمیل آزمون‌ها و پیاده‌سازی کنترل‌های باقیمانده، نسخهٔ آغازین را برای پردازش پرونده‌های محرمانهٔ واقعی یا اقدام قضایی نهایی به‌کار نبرید.
