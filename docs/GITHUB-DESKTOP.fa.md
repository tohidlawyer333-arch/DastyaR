# بارگذاری سورس DastyaR با GitHub Desktop

این راهنما برای مخزن خالی `tohidlawyer333-arch/DastyaR` نوشته شده است. فایل‌ها هنوز به‌صورت خودکار از طرف ChatGPT در مخزن ثبت نشده‌اند؛ باید یک بار آن‌ها را از رایانهٔ خودت push کنی.

## ۱. آماده‌سازی

1. فایل ZIP سورس DastyaR را در یک پوشهٔ موقت استخراج کن.
2. GitHub Desktop را از وب‌سایت رسمی نصب و با همان حساب GitHub وارد شو.
3. در GitHub Desktop گزینهٔ **File → Clone repository** را باز کن، زبانهٔ **URL** را انتخاب کن و این نشانی را وارد کن:

   `https://github.com/tohidlawyer333-arch/DastyaR.git`

4. یک مسیر محلی انتخاب کن و Clone را بزن. اگر مخزن خالی باشد، ممکن است GitHub Desktop پیام دهد چیزی برای checkout وجود ندارد؛ اگر پوشهٔ محلی ساخته شد، ادامه بده. اگر Clone کامل نشد، از روش جایگزین انتهای این راهنما استفاده کن.

## ۲. کپی فایل‌ها

1. پوشهٔ استخراج‌شدهٔ ZIP را باز کن. داخل آن باید پوشه‌ای به نام `DastyaR` باشد.
2. **محتویات داخل پوشهٔ `DastyaR`** را کپی کن، نه خود پوشهٔ `DastyaR` را به‌عنوان یک زیرپوشهٔ دیگر.
3. محتویات را در پوشهٔ محلی‌ای که GitHub Desktop برای مخزن انتخاب کرده paste کن. فایل‌ها و پوشهٔ مخفی `.github` نیز باید کپی شوند.
4. در GitHub Desktop باید فهرست تغییرات دیده شود. فایل `resources/goose/goose.exe` در ZIP سورس وجود ندارد؛ GitHub Actions آن را از انتشار رسمی دریافت و پیش از بسته‌بندی بررسی می‌کند.

## ۳. Commit و Push

1. در پایین پنجرهٔ GitHub Desktop، در **Summary** بنویس: `Add DastyaR Windows desktop source`.
2. روی **Commit to main** بزن.
3. سپس روی **Push origin** کلیک کن.
4. اگر خطای مجوز یا ردشدن push دیدی، متن کامل خطا را نگه دار؛ این خطا باید در مجوز/تنظیمات GitHub برطرف شود، نه با حذف فایل‌های پروژه.

## ۴. اجرای بیلد در GitHub Actions

1. مخزن را در GitHub باز کن و زبانهٔ **Actions** را انتخاب کن.
2. گردش کار **Build DastyaR for Windows** باید با push شاخهٔ `main` شروع شود.
3. وارد اجرای تازه‌شده شو و منتظر پایان job بمان.
4. فقط اگر وضعیت اجرا **Success** شد، در بخش **Artifacts** بستهٔ `DastyaR-Windows-Installers` را دانلود کن. این بسته باید فایل نصب `.exe` و فایل قابل‌حمل `.zip` داشته باشد.
5. اگر اجرا Failed شد، وارد job شو و بخش قرمز خطا را بفرست تا علت واقعی بررسی شود. تا قبل از موفقیت Actions، نسخهٔ نصبی آماده محسوب نمی‌شود.

## اگر Clone مخزن خالی جواب نداد

1. GitHub Desktop را باز کن و **File → New repository** را انتخاب کن.
2. نام را `DastyaR` بگذار و مسیر محلی جدیدی انتخاب کن. گزینهٔ ساخت README را خاموش بگذار تا فایل‌های سورس تداخل پیدا نکنند.
3. بعد از ساخت مخزن محلی، محتویات پوشهٔ استخراج‌شدهٔ سورس را داخل همین پوشهٔ محلی کپی کن.
4. در GitHub Desktop، از **Repository → Repository settings → Remote** نشانی origin را به `https://github.com/tohidlawyer333-arch/DastyaR.git` تنظیم کن؛ اگر Remote وجود ندارد، آن را اضافه کن.
5. Commit to main و سپس Push origin را انجام بده. اگر GitHub بگوید شاخه‌ها تاریخچهٔ متفاوت دارند، force-push نکن؛ خطا را بفرست تا با حفظ تاریخچه حل شود.

## نکات امنیتی

- هیچ API key، گذرواژه، اطلاعات موکل یا فایل واقعی پرونده را وارد مخزن نکن.
- خروجی Actions فقط یک بیلد است؛ صحت کارکرد ACP، رمزگذاری، ذخیره‌سازی و قابلیت‌های حقوقی باید جداگانه آزمایش شوند.
- این نسخهٔ آغازین برای پرونده‌های محرمانهٔ واقعی یا ارسال قضایی نهایی تأیید نشده است.
