# مشخصات اجرایی و نقشهٔ راه

## تصمیم‌های قطعی

- محصول: DastyaR؛ عامل داخل رابط «دستیار دفتر وکالت» نام دارد.
- معماری: برنامهٔ مستقل دسکتاپ، موتور Goose با ACP.
- هدف انتشار: نصاب EXE و ZIP قابل‌حمل ویندوز از GitHub Actions.
- ذخیره‌سازی: محلی و رمزگذاری‌شده؛ کوکی‌های مرورگر عدل ایران در پارتیشن محلی.
- حالت اختیار: از خواندن تا اجرای فرمان/کنترل رایانه؛ پروفایل «دسترسی کامل با تأیید وکیل برای هر گام» باید پیش‌فرض امن داشته باشد.
- سند: کتابخانهٔ قالب، فرم متغیر و پیش‌نویس مجزا از نمونهٔ اصلی.
- منابع حقوقی: طبقه‌بندی توسط وکیل، ورود لینک و فایل و توسعهٔ بعدی واکشی/استخراج امن.
- آرشیوها: ZIP/RAR/7z و سایر فرمت‌های پشتیبانی‌شده توسط 7-Zip، با استخراج موقت و بدون اجرای محتویات.
- صوت: ذخیرهٔ فایل ضبط‌شده رمزگذاری‌شده؛ تبدیل گفتار و ترجمه در فاز بعدی.

## ارائه‌دهندگان

نسخهٔ آغازین Gemini، OpenRouter، OpenAI API، DeepSeek، Hugging Face و مسیر ChatGPT/Codex را فهرست می‌کند. نام مدل و کلید برای همهٔ سرویس‌ها یکسان نیست و شناسهٔ صحیح provider/model باید در آزمون با نسخهٔ بسته‌بندی‌شدهٔ Goose تأیید شود. هیچ روش عمومی و مجاز برای تضمین دریافت خودکار «کلید رایگان» برای حساب‌های مختلف وجود ندارد؛ برنامه کاربر را به مسیر رسمی راهنمایی می‌کند و کلید را پس از ورود/اجازهٔ کاربر ذخیره می‌کند. سهمیه‌های رایگان ممکن است تغییر کنند.

## یکپارچگی Goose

- کاربر فقط DastyaR را اجرا می‌کند؛ Goose CLI فرایند داخلی است و UI جداگانه ندارد.
- تنظیمات Provider/Model، Built-in Extensions و MCP servers داخل تنظیمات DastyaR مدیریت می‌شوند.
- Recipes، subagents، اعلان‌های ACP و انواع درخواست مجوز باید از طریق یک رابط اختصاصی DastyaR تکمیل و آزمون شوند.
- ابزار کنترل رایانهٔ ویندوزی باید بومی و قابل‌ممیزی ساخته شود؛ پشتیبانی macOS موجود در Goose معادل پشتیبانی Windows نیست.

## تعریف اتمام فاز اول

- ساخت Windows x64 روی GitHub Actions موفق شود.
- اولین اجرا بتواند خزانه بسازد و آن را با گذرواژه باز/قفل کند.
- فایل ساده و اعضای آرشیو وارد و رمزگذاری شوند؛ صادرات صریح فقط به مقصد انتخاب‌شده انجام شود.
- ثبت موکل، پرونده، قالب و منبع پس از راه‌اندازی مجدد باقی بماند.
- ابزارهای ACP با حالت دستی آزمون شوند؛ خطا و توقف عامل در رابط نمایش داده شود.
- هیچ رمز، کوکی یا دادهٔ نمونهٔ واقعی داخل مخزن قرار نگیرد.

## موارد ممنوع تا تکمیل آزمون

- استفاده از خزانهٔ آغازین به‌عنوان تنها نسخهٔ نگهداری اسناد حساس.
- ثبت خودکار نهایی هر دادخواست/لایحه.
- تغییر خودکار وضعیت ابلاغ یا تلقی آن به‌عنوان اقدام بی‌اثر.
- اعتماد به ارجاع حقوقی بدون بررسی منبع واقعی و تاریخ اعتبار.
- ادعای دقت «بدون خطا» در OCR یا تشخیص گفتار.
